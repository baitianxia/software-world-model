# M-001：正式知识单路径的本机体验基线

## Outcome

历史本机体验记录表明，用户可以连接精确的本地 Git 来源，让系统通过受控调查形成正式知识，在来源关闭的回答阶段从固定 Snapshot 逐 Need 判断充分性，经独立 Answer Review 后在本机浏览器交付结果。管理 CLI 只作为配置、更新和知识查询入口。

## Completion evidence

- 生产模块化单体和恢复边界完成；
- exact Ark Chat no-tools Adapter Contract Conformance PASS；
- 六类通用模型职责 Capability Evaluation PASS；
- 两个陌生工程六题 Product Validation 逐题不低于相同条件直接调查基线；
- 旧记录报告本机回环浏览器体验 READY；Activation 组合证明的可移植性限制由 Acceptance 披露；
- 生产启用未包含在本 Milestone。
