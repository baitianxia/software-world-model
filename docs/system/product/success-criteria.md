# 长期成功标准

系统达到产品价值必须同时满足：

1. 对目标任务的每个实质 Need 都能从同一固定 Snapshot 重建支持链，或明确返回 Gap。
2. 用户可见 Claim 不扩张正式知识的 Context、Modality 或 Coverage。
3. 来源、生成、准入、发布、答案生成和答案审核之间不存在未授权旁路。
4. 更新后旧知识不会因局部成功被静默删除；并发失败不会产生部分正式状态。
5. 同等输入和资源约束下，系统答案相对直接软件调查不能出现任何重大事实错误，且逐任务不得退步。
6. 资格、有效期和启用范围可机械验证；过期、漂移或未知结果安全关闭。

测试数量、模型分数和一次运行的 PASS 只是证据，不是这些标准本身。
