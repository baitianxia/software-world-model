# 产品愿景与边界

Software World Model 面向需要持续理解软件系统的人和 Agent。它把经授权的软件来源转化为有上下文、来源证据和正式状态的知识，使后续任务能够在固定版本上复用、审核并诚实表达缺口。

平台的价值不在于保存更多文本，而在于建立一条可证明的路径：来源观察形成候选知识，经独立准入和原子发布成为正式知识；任务只能从固定 Snapshot 使用这些知识，并在交付前接受独立复核。

## 产品承诺

- 软件结论可追溯到被授权的精确来源和上下文。
- 已发布知识可跨任务复用，而不依赖某次模型会话记忆。
- 不充分、冲突、未知和运行结果未知都被显式披露。
- 模型可以规划、提议和审核，但不能自行获得来源权限或写入正式知识。
- 系统辅助答案在同等资源约束下不得低于直接调查软件来源的基线。
- 对不同工程、语言、框架和问题类型使用同一套证据流程；扩展来源能力不能通过在问答层增加题型补丁实现。

## 非目标

- 不把原始仓库、日志或模型输出直接称为正式知识。
- 不构建通用自治 Agent 平台、无限工作流引擎或隐藏的来源访问旁路。
- 不在系统规范中冻结某一迭代的模型、Provider、数据集或发布时间。
- 不因评测通过自动执行生产启用。
- 不承诺每个问题都有肯定答案；超出已授权来源、文本能力或固定版本边界的问题必须如实披露证据缺口。
