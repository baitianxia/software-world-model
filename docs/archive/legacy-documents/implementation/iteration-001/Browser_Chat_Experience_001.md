## 普通用户可以做什么

1. 在浏览器中打开项目问答页面。
2. 输入本地Git项目的绝对路径，分析版本默认使用`HEAD`。
3. 可把读取范围限制到某个目录或文件；不填写比较起点时分析一个固定版本，填写后比较两个固定版本。
4. 直接询问实现流程、异常分支、调用关系或版本变化。
5. 在同一对话中继续追问。服务只保留最近三条用户问题帮助理解指代；历史模型回答不会再次进入源码调查，避免上一轮长答案污染下一轮目标。

页面不会让用户填写知识范围、来源标识、绑定标识、调查预算或知识快照。连接项目时，服务会把输入版本解析成完整提交编号，后续调查始终读取该固定Git对象，不读取未提交的工作区内容，也不会修改项目。

首轮问答会优先完整读取所选范围内常见的项目说明与根构建文件。中文问题要求正式事实使用中文；若模型首次返回其他语言，系统会拒绝该批事实并在有限次数内修正。面向审计保存的知识缺口仍保留完整内部记录，但浏览器只展示本地化的“已确认 / 尚未确认”内容，不显示内部英文模板。连续两次源码搜索没有命中时，系统禁止继续更换同义词盲搜，要求改读先前目录清单中的具体文件或停止。

## 启动当前体验环境

先确认当前终端已配置`ARK_API_KEY`环境变量，然后在项目根目录运行：

```bash
PYTHONPATH=src python3 -m software_world_model.interface.http_api \
  --database var/browser-experience/swm.sqlite3 \
  --host 127.0.0.1 \
  --port 8765 \
  --enable-activated-model \
  --conformance-result var/conformance-v8/CC-ARK-CHAT-NO-TOOLS-001-ccrun_66bbedf18020445c9df5fac11526fda1.json \
  --activation-environment local-browser
```

随后打开`http://127.0.0.1:8765/`。安装项目后，也可以使用`swm-browser`作为相同服务的命令入口；仍需提供上述数据库、接口验证结果和体验环境参数。

## 无认证情况下的安全边界

“不需要认证”只适用于同一台电脑上的人工体验。当前服务会拒绝`0.0.0.0`、局域网地址或公网地址，只接受`127.0.0.1`、`::1`和`localhost`。页面与接口同源，不开放跨站调用；页面使用内容安全策略，不加载第三方脚本或图片。

不要通过端口转发、反向代理或修改监听限制把该版本提供给其他设备。若以后需要团队共享或公网发布，必须另行实现访问控制、审计、请求限流和部署边界。

## 到期与变化处理

模型、接口适配、配置指纹或通用问答实现发生变化，或者能力证明与产品验收记录到期后，体验服务会在启动或执行前停止。重新完成评估和产品验收后，需要为新的证明创建新的本机体验数据库与启用记录；不能继续复用本文件记录的旧资格。
